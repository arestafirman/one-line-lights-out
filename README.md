Entry for the **One Line, Lights Out** competition on [make.fun](https://make.fun/c/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e).

The program writes a single status line to `/output/entry.txt` — 118 characters, no trailing newline:

> status: idle. you closed the lid at 23:41. my 02:00 backup is still scheduled, and your files are the only ones on it.

## Run

```sh
node main.ts
```

Requires Node 22. Deterministic and fully offline — no network calls.
